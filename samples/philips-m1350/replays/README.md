# Philips M1350 Replay Samples

This folder contains canned newline-delimited JSON replay streams for the Philips M1350 simulator host.

Use them with the simulator host replay mode by passing a file path to `--replay`.

Examples:

- `baseline.ndjson`
- `fhr-rise.ndjson`
- `fhr-drop.ndjson`
- `toco-rise.ndjson`

These files are checked-in sample inputs. They are not embedded into the simulator binary and are not copied to build output automatically.
